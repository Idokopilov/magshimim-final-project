# Magshimim Final Project

A final project developed under Magshimim program, focused on writer classification using natural language processing and machine learning techniques.

## Project Overview

The goal of this project is to classify written responses by their source and distinguish between different types of writers, including human-written text and AI-generated text.

The project explores how textual patterns, representations, and similarity-based methods can be used to identify the origin of a response. It combines data preprocessing, feature extraction, model experimentation, and performance evaluation in order to better understand how different writing sources can be separated computationally.

## Main Objectives

- Build a practical NLP pipeline for writer classification
- Compare different approaches for representing and analyzing text
- Evaluate how well machine learning methods can distinguish between human and AI-generated responses
- Explore the strengths and limitations of similarity-based and embedding-based approaches

## Project Approach

The project began with classical NLP methods based on TF-IDF vectorization and cosine similarity between sentence representations and class-level reference vectors.

Later, more advanced approaches were explored, including embedding-based representations and machine learning models for improving classification quality and overall robustness.

The workflow included:

- text preprocessing and organization
- feature extraction
- exploratory data analysis
- model experimentation
- evaluation using classification metrics
- result comparison and interpretation

## Evaluation

The project was evaluated using common machine learning metrics and analysis tools, including:

- accuracy
- precision
- recall
- confusion matrix
- classification report

Special attention was given to understanding model behavior and not only final scores, with an emphasis on improving the quality of classification between different writer types.
